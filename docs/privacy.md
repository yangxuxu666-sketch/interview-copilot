# 数据与隐私

## 本地保存

应用默认只在 `127.0.0.1` 运行，本地页面使用启动会话认证和同源检查。默认数据目录：

| 平台与版本 | 路径 |
|---|---|
| Windows 源码 | `InterviewCopilot/data/` |
| Windows 独立版 | `%LOCALAPPDATA%\InterviewCopilot` |
| Mac 源码与独立版 | `~/Library/Application Support/InterviewCopilot` |

简历、公司资料、设置、转写、回答和反馈保存为本地文字文件，资料本身未加密。导入时保留提取后的文字，不复制原始文档。API 密钥在 Windows 使用当前账户的 DPAPI，在 Mac 使用钥匙串；页面不会回显保存的密钥。

`--data-dir` 可以指定其他数据目录。使用不同目录、系统账户或版本时可能看到不同资料，应先确认运行位置再处理数据。更换 Windows 账户或电脑后需要重新配置密钥。

## 发送到服务商的内容

- **云端语音识别**：开始监听后，电脑播放的音频发送到所选的语音服务。千问模式为连续音频流，自定义兼容接口按短音频片段上传。
- **DeepSeek**：生成回答、准备或复盘时，发送问题、选中的资料片段、回答要求以及有限历史和反馈。
- **本地识别**：Windows 源码版可使用本地模型转写；模型首次下载需要联网。生成回答仍使用配置的 DeepSeek API。

应用不把原始录音写入磁盘。语音和模型服务如何处理接收的数据，由相应服务商的条款与配置决定。输入公司名称不会自动进行互联网搜索。

## 分享与反馈

仓库和干净构建包不应包含个人资料、已配置的密钥或运行记录。给朋友分发时使用干净的安装包，不要压缩正在使用的数据目录。提交 Issue、截图或日志前，移除密钥、会话标识和私人内容。

窗口透明度只是显示设置。Windows 的共享排除功能依赖捕获软件支持，不保证所有共享方式生效；Mac 不提供此功能。
