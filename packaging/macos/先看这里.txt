面试伴航 · Mac 安装启动包（云端识别版，待 Mac 实机验证）

这是苹果电脑的源码启动包，不是已编译的 .app 或 .dmg。
当前在 Windows 上完成适配和自动检查，还没有在真实 Mac 上验证录音、权限和小窗。
适配目标为 macOS 13 或更新版本，Apple 芯片和 Intel 芯片均保留构建路线。

首次使用
1. 把压缩包全部解压到一个固定文件夹。
2. 双击“启动面试伴航.command”。首次需要 Python 3.13；如果没有，启动器会打开 Python 官网。
   官网选择“macOS installer”，安装后再次双击启动器；不需要 Xcode 或 Homebrew。
3. 第一次会从 PyPI 下载语音识别和界面组件，需要联网。以后直接双击启动器即可。
4. 页面打开后，在“连接与设置”填写自己的 DeepSeek API 和云端语音识别 API。
5. 上传自己的简历和资料，在监听界面启动监听。系统要求时，允许相应的“屏幕与系统音频录制”权限。
   从源码启动时，系统权限中可能显示 Python 或终端；允许后按系统提示重新打开程序。
6. 使用期间保留启动时的终端窗口；退出请使用网页中的退出按钮。

本包没有任何发送者的 API 密钥、简历或面试记录。你的资料保存在：
~/Library/Application Support/InterviewCopilot
API 密钥由 Mac 钥匙串保存；如果出现钥匙串授权弹窗，请按系统提示操作。

此版本调用你配置的云端识别服务；不带本地 Whisper 模型。系统声音会发送给你的语音识别服务，
生成回答时会把相关资料发送给你的 DeepSeek 服务。默认不采集麦克风。
Mac 版小窗支持移动和透明度，暂不支持共享时隐藏。

如果系统拦截来源未验证的文件，请按 Apple 的官方说明，在系统设置→隐私与安全性中检查并确认来源。
https://support.apple.com/guide/mac-help/mh40616/mac

希望以后不依赖 Python 启动：
在这台 Mac 上双击“制作独立Mac应用.command”，制作原生 .app。
制作成功后，mac-dist 内会出现与当前 Mac 芯片匹配的独立应用压缩包。
这是本地签名版本，尚未做 Apple 开发者签名和公证；跨电脑分享时可能需要系统手动确认。
Apple 芯片生成 arm64 包，Intel 芯片生成 x86_64 包；制作脚本也附有手动 GitHub Actions 双架构构建模板。

发现问题时，请提供终端最后几行错误，或资料目录下的 startup-error.txt。
不要发送 API 密钥或 secrets 文件。
