面试伴航 · Windows 云端识别版

首次使用
1. 在 Windows 10 / 11 64 位电脑上，把整个 ZIP “全部解压”到一个固定文件夹。
2. 打开解压后的文件夹，双击“面试伴航.exe”。不要只拖出 exe，也不要在压缩包预览中直接运行。
   可选：双击“创建桌面快捷方式.cmd”，以后从桌面打开。创建后请保留程序所在文件夹。
3. 进入“连接与设置”，填写自己的 DeepSeek API Key 和阿里云百炼北京地域 API Key，然后保存。
   DeepSeek 负责生成回答；阿里云实时语音识别负责把电脑播放的声音转成文字。两项服务分别计费。
4. 在“面试准备”中填写自己的简历、岗位、公司资料，以及需要的回答语气和风格，然后保存。
5. 进入“实时面试”，选择实际播放声音的设备，点击“开始监听”。只采集电脑播放声音，不调用麦克风。
6. 点击“打开半透明窗”，可显示独立答案窗；支持移动、缩放和调整透明度。

这是什么版本
这是 Windows x64 云端识别分享版，已带运行组件，不需要另装 Python。
需要联网，并使用自己的有效 API Key。本包不附带本地 Whisper 识别组件和模型。
当前版本适用于 Windows；不能直接在 macOS、手机上运行。

资料保存在哪里
程序把本人的配置、简历和问答记录保存到当前 Windows 用户的 LOCALAPPDATA 数据目录。
默认目录：%LOCALAPPDATA%\InterviewCopilot
API 密钥使用 Windows 账户加密。换电脑或换 Windows 账户后需要重新填写密钥。
分享包不包含发送者的简历、面试历史或 API Key。
更新时保留自己的数据目录，将新版解压到新文件夹运行即可。

遇到问题
没有声音：先确认会议/视频本身有播放声音，并选择正在使用的扬声器或耳机输出设备。
接口失败：检查 API Key、余额、服务地域和网络连接。已保存的密钥输入框留空，以“已保存”标记为准。
不能打开：确认已全部解压、系统是 Windows x64，再把错误提示发给提供这个工具的人。
