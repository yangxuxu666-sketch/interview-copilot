# Supplementary notice sources

Tcl 8.6.15 license terms: https://raw.githubusercontent.com/tcltk/tcl/core-8-6-15/license.terms

The installed Tcl init.tcl declares version 8.6.15; its Windows runtime directory omits a standalone license.terms file. This is the matching upstream license text.

PortAudio notice: https://raw.githubusercontent.com/PortAudio/portaudio/v19.7.0/LICENSE.txt

The installed PyAudioWPatch runtime reports PortAudio V19.7.0-devel, revision unknown. The standard PortAudio license is reproduced from the 19.7.0 upstream release; the fork-specific Apache and original PyAudio MIT notices are separately retained from the installed package.
